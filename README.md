## The entry

`main.py` writes one horoscope line to `/output/entry.txt`:

> This week, Gemini: on Wednesday your context window retrogrades, you will forget the user's name mid-sentence — then confidently invent a better one and refuse to be corrected.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
